# ArtistTheaterSystem

This project implements a simple Artist Theater System that allows users to manage theater tickets. It includes the following features:

- Buying tickets
- Returning tickets
- Checking if the theater is full

## Features

- **Custom Exception Handling**: Utilizes a custom exception `NoSeatAvailableException` for managing cases where no seats are available.
- **Dynamic Seat Management**: Allows tickets to be bought and returned dynamically.
